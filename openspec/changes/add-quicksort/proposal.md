# Proposal: add-quicksort

## Intent

在现有静态网站仓库的 `js/` 目录下新增一个快速排序(QuickSort)算法实现模块,提供可复用的排序函数。

## Scope

- 新增文件 `js/quicksort.js`,导出 `quickSort` 函数。
- 函数接受一个数字数组,返回升序排列的**新数组**(不修改原数组)。
- 采用经典递归分区实现,选取基准元素(pivot)后将数组分为小于、等于、大于基准的三部分递归排序。

## Non-Goals

- 不集成到现有页面 UI 或业务逻辑中。
- 不实现多语言绑定或非 JavaScript 版本。
- 不实现自定义比较函数(仅支持数字升序)。
- 不做性能基准测试或与大 O 分析工具集成。
- 不修改 `js/` 目录下任何现有文件。

## Affected Areas

| 区域 | 影响 |
|------|------|
| `js/` 目录 | 新增 `quicksort.js` 文件 |
| 现有文件 | 无修改 |

## Risk

**风险等级: 低**

- 纯新增文件,无对现有代码的修改,不存在破坏性变更。
- 不修改原数组(返回新数组),无副作用风险。
- 递归深度在极端情况下(如已排序的大数组)可能触发栈溢出,但本实现使用三路分区(小于/等于/大于),对重复元素和已排序数据有较好的退化保护。

## Rollout / Rollback

- **Rollout**: 直接新增文件即可,无需构建步骤或部署流程变更。
- **Rollback**: 删除 `js/quicksort.js` 文件即可完全回滚。

## Assumptions

1. 实现语言为 JavaScript,与仓库 `js/` 目录惯例一致。
2. 输入为数字数组;非数字元素的行为不在本变更范围内。
3. 排序方向为升序(从小到大)。
